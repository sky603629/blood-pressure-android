血压参考范围

血压图的浅色区域：高压 90–120 mmHg，低压 60–80 mmHg。

标签参考成人诊室血压：高压低于 90 或低压低于 60 mmHg 为偏低；高压 120–139 或低压 80–89 mmHg 为正常高值；高压达到 140 或低压达到 90 mmHg 为偏高。

家庭连续 5–7 天测量的平均值达到 135/85 mmHg 也应关注。个人目标以医生建议为准，单次读数不能用于诊断。

参考：北京市卫生健康委员会
