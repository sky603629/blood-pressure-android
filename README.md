# 血压日记 Android App

独立原生 Android 应用，用于手动或拍照录入收缩压、舒张压、脉搏和备注，并在本机查看近期趋势。

## 功能

- SQLite 本地保存，应用不申请网络权限。
- 新增、编辑和删除测量记录，可选择测量日期与时间。
- 1.2.1“拍照录入”改用 Tesseract4Android 和随 APK 打包的七段液晶数字专用模型 `ssd_int`；直接调用手机相机，在本机离线识别，不提供相册入口，不需要首次联网下载模型。
- 自动寻找有三行大数字的明亮 LCD，按鱼跃 YE692 的高压、低压、脉搏区域识别；可拖动屏幕四角校正倾斜。模型限制识别数字，使用灰度和两种二值化图片交叉检查；同一字段至少两次可信结果一致才自动填写，有可信冲突则留空。点击“核对无误，保存记录”后才入库。
- 使用 iOS 分组界面风格；测量卡片先显示日期与上午、下午、晚上，再显示高压、低压、脉搏。大字体设置下，数值改为纵向排列，避免挤在一起。
- 查看最近 7 天、30 天、全部记录，或按日期查看当天全部测量；图表按测量先后等距排列，每个点代表一次测量，并非按时间间隔等距。
- 图表默认展开最近 12 次测量，支持左右滑动、双指缩放、双击放大、点选、长按拖动和底部缩略图定位；上一条、下一条、放大、缩小和全览按钮提供同样的操作入口。
- 1.1.1 切换 7 日、30 日、全部或日期筛选时直接更新现有图表；保留页面、滚动位置及已展开的历史记录，避免整页重建造成的闪烁。重复点击已选范围不会重置图表。
- 首页显示最近一次测量和历史记录；历史列表可逐批加载更早的记录，编辑和删除入口在每条记录右上角。
- 将全部记录导出为 CSV 报告，或导出可完整恢复的 JSON 备份。
- 从本应用 CSV 报告或 JSON 备份合并导入；重复记录自动跳过，导入记录加入趋势和日期筛选。
- 输入范围校验；记录用于观察趋势，不提供诊断结论。

## 数据导入与导出

点击首页右上角齿轮，在“数据管理”中选择导出报告、导入数据或备份全部数据。Android 文件选择器会让用户指定文件位置或来源，不需要授予整个存储空间访问权限。导入前会显示新增、重复和无效记录的数量；确认后新增记录会保存到本机 SQLite 数据库。

CSV 适合在表格应用中查看。新版测量时间以“测量于 2026-10-10 08:15:22”的文字形式导出，避免表格软件将其转成列宽不足的日期单元格后显示为 `########`。导入时请保留列名；仍兼容 1.0.0 的分钟、秒和毫秒时间格式。JSON 备份格式不变，保留毫秒级时间和备注，适合完整恢复；导入会合并记录，不会删除本机已有数据。

## 拍照录入

点击首页“拍照录入”，拍摄血压计测量完成后的屏幕。拍照尽量正对屏幕、避开反光并让三个数字清晰。App 接收相机输出的原始照片，处理 EXIF 方向并限制解码尺寸，随后在本机运行 OCR。照片保存在应用私有缓存中；确认保存或退出时清理，不随 CSV/JSON 导出，也不上传。应用移除了依赖带入的网络权限；调用系统相机不需要申请本应用的相机权限或整块存储访问权限。

识别结果和照片一起显示，高压、低压、脉搏均可修改。测量时间默认使用拍照完成的时间，可以手动调整；识别区域排除屏幕上方日期和电量，不把拍照时间宣称为原始测量时间。可点“对齐屏幕四角”，分别拖动四个蓝点对齐整块 LCD 的四角，再点“识别框内读数”；四个角可独立移动，使用透视变换拉正屏幕，然后按鱼跃 YE692 布局分行识别。

模型针对七段数字，但反光、模糊、严重倾斜及屏幕布局变化仍会影响识别。自动定位只接受具有三个数字区域的明亮屏幕；无法定位时提示手动对齐，不猜测缺失数字。预处理将数字高度归一化，降低不同相机分辨率的影响。置信度、重复识别一致、数值范围和高低压关系检查不能排除所有误读，保存前仍须对照血压计核对。

接入依据：[Tesseract4Android](https://github.com/adaptech-cz/Tesseract4Android) 4.9.0，[tessdata_ssd](https://github.com/Shreeshrii/tessdata_ssd) 的 `ssd_int.traineddata`，模型固定到提交 `e493a10a4bf81632506cf24ba99d83854afff9f6`。模型大小 1,442,809 字节，SHA-256 为 `557759383e030694420ee9f6a88e824abae4acf17f7b94415ca07e1152339339`。首次识别从 APK 复制到应用私有目录，并检查大小和摘要；不访问网络。

电脑端使用 Tesseract 5.5.3 对用户提供的 YE692 照片做自动屏幕定位、透视校正、分行和预处理验证，交叉检查得到高压 109、低压 71、脉搏 86。安卓库内置 Tesseract 5.5.1，尚未在手机上验证真实拍摄、原生初始化及交互效果；单张电脑端结果不代表真实照片的整体准确率。逻辑回归另覆盖缺项、冲突、低置信度和选框校验。

开源组件说明及许可证随 APK 放在 `assets/licenses`，也可查看工程 [THIRD_PARTY_NOTICES.txt](app/src/main/assets/licenses/THIRD_PARTY_NOTICES.txt)。

## 覆盖升级与数据保留

1.2.1 的 applicationId 仍为 `com.pressurediary.app`，SQLite 文件仍为 `pressure_diary.db`，表结构和数据库版本均未更改。安装升级 APK 时应直接覆盖安装，不能先卸载应用或清除应用数据。可先从右上角齿轮备份 JSON 留存。

测试发布包继续沿用此前 1.0.0 的本机 Android debug 密钥，只适合当前侧载测试分发。构建脚本会校验新旧 APK 的证书是否一致。应保存好原密钥；未来更换电脑后仍须使用同一密钥才能覆盖升级。

## 构建与验证

在 PowerShell 中运行：

```powershell
cd E:\RUN_Project\keyboard-run-Project82\blood-pressure-android
.\build-apk.ps1
# 构建并签名 Release 测试分发包
.\build-apk.ps1 -Variant release-test
# 依赖已缓存后，可离线构建
.\build-apk.ps1 -Variant release-test -Offline
# 新旧 CSV/JSON 兼容、去重、图表浏览和 OCR 字段对应检查
.\test-behavior.ps1
```

APK 会保存到工程上一级的 `dist` 文件夹，文件名包含版本号。构建使用 JDK 17；Release 测试包使用现有 Android debug 签名，关闭调试标记，不包含第三方 UI 或图表依赖。首次运行逻辑测试时会下载仅用于电脑端测试的 Android JSON 实现，不会打入 APK。
