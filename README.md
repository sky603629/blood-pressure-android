# 血压日记 Android App

独立原生 Android 应用，用于手动记录收缩压、舒张压、脉搏和备注，并在本机查看近期趋势。

## 功能

- SQLite 本地保存，应用不申请网络权限。
- 新增、编辑和删除测量记录，可选择测量日期与时间。
- 查看最近 7 天或 30 天的收缩压、舒张压或脉搏趋势。
- 首页显示最近一次测量数据和历史记录。
- 将全部记录导出为 CSV 报告，或导出可完整恢复的 JSON 备份。
- 从本应用 CSV 报告或 JSON 备份合并导入；重复记录自动跳过，导入记录加入趋势和日期筛选。
- 输入范围校验；记录用于观察趋势，不提供诊断结论。

## 数据导入与导出

点击首页右上角齿轮，在“数据管理”中选择导出报告、导入数据或备份全部数据。Android 文件选择器会让用户指定文件位置或来源，不需要授予整个存储空间访问权限。导入前会显示新增、重复和无效记录的数量；确认后新增记录会保存到本机 SQLite 数据库。

CSV 适合在表格应用中查看，导入时请保留应用导出的列名和测量时间格式。JSON 备份保留毫秒级时间和备注，适合完整恢复；导入会合并记录，不会删除本机已有数据。
